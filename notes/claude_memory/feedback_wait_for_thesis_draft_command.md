Do not write actual thesis chapter drafts (e.g., Chapter 4 findings prose) proactively, even when it's the obvious next step after a technical fix or discussion. Wait for the user to explicitly ask for the draft.

**Why:** user said directly: "thank you for drafting me the chapter 4, but you must wait for my command when writing thesis drafts." This was after I wrote a full Chapter 4 draft unprompted as part of "proceed with your recommendation."

**How to apply:** Technical notes, findings summaries, and evidence tables are fine to write proactively (e.g., to an .md notes file) — the user explicitly welcomed this as "our notes." The line is specifically *thesis-prose drafting* (content meant to go into the actual manuscript chapters) vs. working notes/evidence for later drafting. When in doubt, write it as a note/finding rather than polished chapter prose, and let the user ask for the draft explicitly.
