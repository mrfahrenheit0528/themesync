ThemeSync thesis consultations — with both the **adviser** and the separate
**statistics/methodology consultant** role — are conducted asynchronously
through Google Chat, not a scheduled in-person or video meeting.

**Why:** stated directly by the user for the adviser (2026-09-16), then
confirmed to apply to the consultant too (2026-09-22, "our consultant is
unavailable this week and we will just do the consultation through google
chat") — superseding the earlier assumption (baked into
`notes/adviser_consultation_checklist.md`'s original framing) that there'd
be a live meeting to walk through prep material. Treat this as the default
for *any* thesis-committee-adjacent consultation on this project unless the
user says otherwise for a specific one.

**How to apply:** when prepping material for either person (e.g.
`notes/adviser_consultation_checklist.md`, `notes/consultant_cheatsheet.md`),
favor a format that reads well as standalone chat message text — self-
contained, skimmable, sendable as-is — over a live-presentation script
("say this," "have this diagram open," "point to Figure 4") that assumes
someone is presenting in person with visual aids on hand. A first draft
built as a presentation flow should get revised into chat-ready message
blocks once this comes up, the same way `consultant_cheatsheet.md` was
revised on 2026-09-22. See [[project_themesync_thesis_context]].
